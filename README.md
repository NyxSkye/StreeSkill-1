## 🎯 About

StreeSkill addresses the critical gap in women's skill development by providing:
- 📚 **100+ Curated Courses** across Technology, Business, Finance, and Design
- 👩‍🏫 **Expert Women Instructors** teaching practical, career-ready skills
- 🤝 **Community Support** with peer learning and mentorship
- 🏆 **Gamified Learning** with achievements, certificates, and progress tracking

**Built for**: WIE HackEarth-2025 Hackathon  
**Category**: Social Impact & Education Technology

---

## ✨ Features

### 🏠 Home Dashboard
- Personalized welcome and user profile
- Visual impact metrics (courses, hours, certificates, skill score)
- Continue learning section with in-progress courses
- Trending courses with ratings and enrollment stats

### 📖 Course Catalog
- Category-based filtering (Technology, Marketing, Finance, Design, Business)
- Detailed course information with instructor profiles
- Integrated video player for course previews
- Module breakdown and learning path

### 👥 Community Hub
- Social feed with user posts and success stories
- Community engagement metrics (12.5K+ members)
- Like, comment, and share functionality
- Create and share achievements

### 👤 User Profile
- Achievement badges and milestones
- Completed courses with certificate downloads
- Learning statistics and progress visualization
- Settings and preferences management

## 🚀 Quick Start

### Prerequisites
- Flutter SDK 3.10+
- Android Studio or VS Code
- Android Emulator or iOS Simulator

### Installation

```bash
# 1. Clone the repository
git clone <repository-url>
cd streeskill

# 2. Install dependencies
flutter pub get

# 3. Run the app
flutter run
```

**That's it!** The app will launch with demo data ready for evaluation.
